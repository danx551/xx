Orbite, sans installation

Ton application de révision fonctionne directement dans Google Chrome, depuis ce dossier. Tu n’as besoin ni de Node.js, ni de Python, ni d’un terminal, ni d’Internet.

Ouvrir Orbite →

Sur Windows : les étapes exactes

  1. Sur GitHub, ouvre la branche indiquée avec cette livraison, puis clique sur Code → Download ZIP.
  2. Dans l’Explorateur Windows, fais un clic droit sur le ZIP et choisis Extraire tout…. Choisis un emplacement que tu conserveras, par exemple ton dossier Documents.
  3. Ouvre le dossier extrait, puis le sous-dossier ORBITE_HTML.
  4. Fais un clic droit sur index.html, puis Ouvrir avec → Google Chrome. Si Chrome est déjà ton navigateur par défaut, un double-clic suffit. Windows peut masquer l’extension : le fichier peut simplement s’appeler « index ».
  5. L’adresse commence par file:///. Tu peux ensuite te déconnecter d’Internet et réviser. Ajoute cette page aux favoris de Chrome si tu veux la retrouver facilement.
Il faut extraire le ZIP avant d’ouvrir la page. Conserve tout le dossier ORBITE_HTML : déplacer uniquement index.html sépare la page de ses ressources.

Garder et transférer ta progression

Chrome conserve la progression dans son stockage local. Après avoir coché un QCM ou travaillé un exercice, tu peux fermer puis rouvrir le même fichier avec le même profil Chrome.

  • Exporte régulièrement : dans Orbite, ouvre les paramètres avec la roue dentée en bas du menu, puis clique sur Exporter ma progression. Chrome télécharge un fichier JSON.
  • Pour récupérer ta progression de l’ancienne application : exporte-la depuis l’ancienne version, puis utilise Importer une sauvegarde dans cette version autonome. Le format reste compatible. L’import remplace la progression actuelle.
  • Avant de déplacer ou renommer le dossier, changer de navigateur ou de profil : exporte ta progression. Ouvre ensuite le nouvel emplacement et importe ton fichier JSON. Le stockage des pages file:// dépend du navigateur et de l’emplacement du fichier ; il ne peut pas être garanti entre plusieurs emplacements.
  • En navigation privée ou si les réglages de Chrome bloquent le stockage, la sauvegarde automatique peut être indisponible. Un message l’indique ; l’application reste utilisable et tu peux exporter tes réponses avant de fermer.

Documents, formules et impression

Les pages des documents sont incluses comme images locales pour afficher leurs figures sans dépendre d’un lecteur PDF intégré. Clique sur une page pour l’ouvrir en grand. Les PDF originaux se trouvent dans documents et s’ouvrent avec le lecteur de Chrome ; leur affichage peut dépendre des réglages PDF de ton navigateur. Si Chrome propose de télécharger un PDF, les images locales permettent toujours de consulter son contenu dans Orbite.

Le bouton Imprimer / PDF utilise la boîte de dialogue de Chrome. Choisis Enregistrer au format PDF pour conserver une fiche. Toutes les polices des formules sont intégrées : aucune connexion à un CDN n’est nécessaire.

Ce qui ne change pas

Les corrections du professeur n’étant pas fournies, les 193 réponses restent des corrections originales. Les lectures graphiques sont approchées, les priorités ne prédisent pas le sujet, et les réponses rédigées ainsi que les notes de DS reposent sur une auto-évaluation guidée. Les chronomètres continuent même si tu fermes la page. Leur échéance dépend de l’horloge de ton ordinateur.

Vérifier ta copie sans terminal

Tu peux ouvrir TESTER_ORBITE.html dans Chrome puis cliquer sur « Lancer les vérifications locales ». Le rapport indique le protocole réellement utilisé et teste les contenus, QCM, exercice, recherche, formules, pages et favoris. La progression initiale est restaurée à la fin. Pour vérifier la persistance après fermeture : dans index.html, réponds à un QCM, ferme Chrome et rouvre le même fichier ; ta réponse doit être retrouvée. Ces tests facultatifs ne demandent aucune installation.

Composition du dossier

  • index.html : fichier à ouvrir.
  • ressources/ : JavaScript classique et styles ; données pédagogiques et polices intégrées.
  • documents/ : les dix PDF originaux.
  • pages/ : les 73 pages d’origine en images.
  • CONTENU.json : inventaire et empreintes des contenus, pour la traçabilité.
  • LICENCES.txt : licences des bibliothèques incluses.

Aucune donnée n’est envoyée à un serveur. N’ouvre que les fichiers de la livraison provenant de ton dépôt ; conserve tes sauvegardes JSON sur ton ordinateur.
